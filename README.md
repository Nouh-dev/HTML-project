# Tech Store Landing Page

A simple gaming/tech store landing page built using HTML and CSS.

## Features

- Header with navigation menu
- Hero section with search input
- Trending games section
- Product cards layout
- Simple modern UI design

## Project Structure

style.css
images/

    trending-04.jpg

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Roboto)

## How to Run

1. Download or clone the repository
2. Open index.html in any browser

## Purpose

This project was created for learning HTML and CSS layout, Flexbox, and basic UI design.
